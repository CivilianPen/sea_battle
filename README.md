# sea_battle

<!--Описание-->
## Описание

Веб-приложение для выйгрыша призов в формате морского боя

<!--Установка-->
## Установка (Linux)

1. Клонирование репозитория 

```git clone https://github.com/CivilianPen/sea_battle```

2. Переход в директорию

```cd seabattle\seabattle```

3. Установка зависимостей

```pip3 install -r requirements.txt```

4. Запуск

```python3 manage.py runserver```
